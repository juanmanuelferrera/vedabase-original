### CC Madhya 11.11

> আকারাদপি ভেতব্যং স্ত্রীণাং বিষয়িণামপি ৷\
> যথাহের্মনসঃ ক্ষোভস্তথা তস্যাকৃতেরপি ৷৷ ১১ ৷৷ ॥১১॥

ākārād api bhetavyaṁ
strīṇāṁ viṣayiṇām api
yathāher manasaḥ kṣobhas
tathā tasyākṛter api

*ākārāt*—dos traços corporais; *api*—até mesmo; *bhetavyam*—a ser temido; *strīṇām*—de mulheres; *viṣayiṇām*—de pessoas materialistas; *api*—até mesmo; *yathā*—como; *aheḥ*—de uma serpente; *manasaḥ*—da mente; *kṣobhaḥ*—agitação; *tathā*—assim; *tasya*—dela; *ākṛteḥ*—do aspecto; *api*—até mesmo.

**" 'Assim como a pessoa fica imediatamente amedrontada ao ver uma serpente viva, ou mesmo a forma de uma serpente, da mesma forma aquele que se esforça pela autorrealização deve temer uma pessoa materialista e uma mulher. De fato, ele não deve sequer lançar um olhar sobre seus traços corporais.'**

Esta é uma citação do Śrī Caitanya-candrodaya-nāṭaka (8.24).
