### CC Madhya 24.25

> ‘কুর্বন্তি’-পদ এই পরস্মৈপদ হয় ।\
> কৃষ্ণসুখনিমিত্ত ভজনে তাৎপর্য কহয় ॥২৫॥

'kurvanti'-pada ei parasmaipada haya

kṛṣṇa-sukha-nimitta bhajane tātparya kahaya

*kurvanti*—eles fazem (para outros); *pada*—a palavra; *ei*—esta; *parasmaipada*—uma forma verbal que indica coisas feitas para outros; *haya*—é; *kṛṣṇa-sukha-nimitta*—para satisfazer Kṛṣṇa; *bhajane*—em serviço devocional; *tātparya*—o significado; *kahaya*—diz-se.

**"A palavra kurvanti, que significa 'eles fazem algo para outros', é uma forma do verbo 'coisas feitas para outros'. Ela é usada em relação ao serviço devocional, que deve ser executado para a satisfação de Kṛṣṇa. Este é o sentido da palavra kurvanti.**

Em sânscrito, o verbo "fazer" tem duas formas, tecnicamente chamadas de parasmaipada e ātmanepada. Quando as coisas são feitas para a satisfação pessoal de alguém, a forma é chamada de ātmanepada. Nesse caso, a palavra "fazer" em português é kurvante em sânscrito. Quando as coisas são feitas para outros, a forma verbal muda para kurvanti. Foi assim que Śrī Caitanya Mahāprabhu informou a Sanātana Gosvāmī que, no verso ātmārāma, o verbo kurvanti significa que as coisas devem ser feitas somente para a satisfação de Kṛṣṇa. Isso é corroborado pelo gramático Pāṇini. O verbo forma-se como ātmanepada quando o trabalho deve ser feito para o próprio benefício de alguém, e, quando é feito para outros, é chamado de parasmaipada. Dessa maneira, o verbo forma-se conforme algo seja feito para a autossatisfação de alguém ou para a satisfação de outrem.
