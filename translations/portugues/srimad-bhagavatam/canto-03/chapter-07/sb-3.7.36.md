### SB 3.7.36

> अनुव्रतानां शिष्याणां पुत्राणां च द्विजोत्तम ।
> अनापृष्टमपि ब्रूयुर्गुरवो दीनवत्सलाः ॥३६॥

anuvratānāṁ śiṣyāṇāṁ

putrāṇāṁ ca dvijottama

anāpṛṣṭam api brūyur

*guravo dīna*-vatsalāḥ

*anuvratānām*—os seguidores; *śiṣyāṇām*—dos discípulos; *putrāṇām*—dos filhos; *ca*—também; *dvija-uttama*—ó melhor dentre os *brāhmaṇas*; *anāpṛṣṭam*—aquilo que não foi perguntado; *api*—mesmo assim; *brūyuḥ*—descreva por favor; *guravaḥ*—os mestres espirituais; *dīna-vatsalāḥ*—que são bondosos para com os necessitados.

**Ó melhor dentre os *brāhmaṇas*, aqueles que são mestres espirituais são muito bondosos para com os necessitados. São sempre bondosos para com seus seguidores, discípulos e filhos, e, sem ser por eles solicitados, o mestre espiritual descreve tudo o que é conhecimento.**

Há muitos assuntos a serem conhecidos do mestre espiritual genuíno. Os seguidores, discípulos e filhos estão todos no mesmo nível para o mestre espiritual genuíno, que é sempre bondoso para com eles e sempre lhes fala sobre assuntos transcendentais, mesmo sem ser solicitado. Essa é a natureza do mestre espiritual genuíno. Vidura apelou a Maitreya Muni para que falasse sobre assuntos que ele poderia não ter perguntado.
