### 22

22. 《圣典博伽瓦谭》

在玛雅瓦迪桑雅西转而追随采坦尼亚·马哈帕布（Mahāprabhu）的道路之后，许多学者和好学之人来到贝拿勒斯拜访主。由于不可能每个人都在祂的住处见到采坦尼亚·马哈帕布，人们便排成队，等祂前往维施瓦纳特（Viśvanātha）和宾杜玛德瓦（Bindumādhava）神庙途中一见。一天，主带着祂的同伴昌德拉谢卡拉阿查里亚（Candraśekhara Ācārya）、帕茹阿玛南达（Paramānanda）、塔帕那·弥施拉（Tapana Miśra）、萨纳坦那·哥斯瓦米（Sanātana Gosvāmī）等人去神庙时，祂唱道：

haraye namaḥ kṛṣṇa yādavāya namaḥ

gopāla govinda rāma śrī-madhusūdana

当主这样一边唱颂一边起舞时，数以千计的人聚集到祂周围，而当主唱颂时，他们高声呼喊。那震动声如此喧腾，以致坐在附近的普拉卡沙南达·萨茹阿斯瓦蒂（Prakāśānanda Sarasvatī）立刻带着弟子们加入了人群。他一看到主采坦尼亚美丽的身体，以及祂与同伴们共舞的情景，也加入进来，开始唱道：「Hari! Hari!」贝拿勒斯的全体居民看到主采坦尼亚狂喜的舞蹈，无不惊叹。然而，主采坦尼亚一看见玛雅瓦迪桑雅西，便止住了祂持续的狂喜，停下了舞蹈。主刚一停止唱颂和舞蹈，普拉卡沙南达·萨茹阿斯瓦蒂就倒在祂的脚下。主采坦尼亚想要阻止他，说道：「哦，您是整个世界的灵性导师，是世界导师（jagad-guru），而我甚至比不上您的弟子。因此，您不应该崇拜像我这样低下的人。您就像至尊的梵一样，如果我让您倒在我的脚下，我将犯下极大的冒犯。虽然您没有二元的见解，但为了教导一般大众，您不应该这样做。」

「以前我曾多次说您的坏话，」普拉卡沙南达·萨茹阿斯瓦蒂答道，「现在，为了使自己摆脱冒犯的后果，我倒在您的脚下。」随后他引用了韦达文献中的一节诗，其中说，即使是获解脱的灵魂，一旦冒犯至尊主，也会再次沦为物质污染的牺牲品。普拉卡沙南达·萨茹阿斯瓦蒂接着又引用《圣典博伽瓦谭》（10.34.9）中的另一节诗，讲的是南达·马哈茹阿佳被一条蛇攻击，那条蛇前世是维迪亚达尔阿尔契塔（Vidyādharārcita）。当蛇被奎师那的莲花足触碰时，它恢复了先前的身体，摆脱了罪恶行为的反作用。主采坦尼亚听到自己被等同于奎师那，便温和地提出抗议。祂想警告一般大众，不要把至尊主与任何生物相比，尽管祂本人就是至尊主，祂仍然反对这种比较，以此来教导我们。因此祂说，把任何人与至尊主奎师那相比，是最大的冒犯。主采坦尼亚始终主张，维施努，至尊人格神，是伟大的，而生物无论多么伟大，都只是微小的。就此，祂引用了《帕德玛往世书》中的一节诗，该诗见于外士那瓦怛特罗（《哈里-巴克提-维拉萨》1.73）：「把至尊主与布茹阿玛和希瓦这样最伟大的半神人相比的人，必须被视为头号无神论者。」

「我明白您就是至尊人格神奎师那，」普拉卡沙南达·萨茹阿斯瓦蒂接着说，「即使您以奉献者的身份示人，您仍然值得崇拜，因为在学识和觉悟上，您都胜过我们所有人。因此，我们诽谤您，就犯下了最大的冒犯。请原谅我们。」

一位奉献者如何成为所有超然主义者中最伟大的，《圣典博伽瓦谭》（6.14.5）中说：

muktānām api siddhānāṁ

nārāyaṇa-parāyaṇaḥ

sudurlabhaḥ praśāntātmā

koṭiṣv api mahāmune

「有许多获解脱的灵魂和臻于完美的灵魂，但在他们所有人当中，最好的是至尊人格神的奉献者。至尊主的奉献者总是平静安宁，而他们的完美，即使在千万人中也极为罕见。」普拉卡沙南达还引用了另一节诗(SB 10.4.46)，其中说，当一个人冒犯奉献者时，他的寿命、繁荣、名声、达尔玛以及上级权威的祝福都会丧失殆尽。普拉卡沙南达还引用《圣典博伽瓦谭》（7.5.32）中的另一节诗，说受制约的灵魂的一切疑虑，在触及至尊人格神的莲花足时便会消失。然而，除非得到主的纯粹奉献者莲花足之尘的祝福，否则无法触及至尊主的莲花足。换句话说，除非得到主的另一位纯粹奉献者的恩惠，否则一个人无法成为至尊人格神的纯粹奉献者。

「现在我皈依您的莲花足，」普拉卡沙南达·萨茹阿斯瓦蒂说，「因为我想被提升到至尊主奉献者的地位。」

这样交谈之后，普拉卡沙南达·萨茹阿斯瓦蒂和主采坦尼亚一同坐下。「您所说的玛雅瓦迪哲学中的缺陷，我们也知道，」普拉卡沙南达说，「的确，我们知道玛雅瓦迪哲学家对韦达经典的所有注释都是错误的，尤其是商卡拉查里亚（Śaṅkarācārya）的注释。商卡拉查里亚对《韦丹塔经》（Vedānta-sūtra）的诠释，全是他想象出来的。您没有按照自己的想象去解释《韦丹塔经》和《奥义书》的经文，而是如其本然地呈现了它们。因此，听了您的解释，我们都很欢喜。这样解释《韦丹塔经》和《奥义书》的经文，除了至尊人格神，没有人能做到。既然您具有至尊主的一切能力，请进一步解释《韦丹塔经》，使我能够受益。」

主采坦尼亚抗议被称为至尊主，祂说：「亲爱的先生，我只是一个普通的生物。我无法知道《韦丹塔经》的真正含义，但维亚萨戴瓦（Vyāsadeva）是纳茹阿亚那的化身，他知道它的真正含义。没有任何普通生物可以按照自己世俗的观念去诠释《韦丹塔经》。为了遏制不择手段的人对《韦丹塔经》的注释，作者维亚萨戴瓦本人已经写下《圣典博伽瓦谭》，作为对《韦丹塔经》的注释。」换句话说，对一部书最好的解释，是作者自己写的。除非作者自己披露其写作背后的目的，否则没有人能理解作者的心意。因此，《韦丹塔经》应当通过《圣典博伽瓦谭》来理解，那是《韦丹塔经》的作者所写的注释。

普拉纳瓦（praṇava），即奥姆卡拉（oṁkāra），是所有《韦达经》的神圣实质。奥姆卡拉在伽雅特里曼陀罗（gāyatrī）中有进一步的解释，与《圣典博伽瓦谭》中的解释完全一致。就此写有四节诗，这些是主奎师那亲自向布茹阿玛讲解的。布茹阿玛又向纳茹阿达讲解，纳茹阿达又向维亚萨戴瓦讲解。这样，《圣典博伽瓦谭》诗节的要义便通过师徒传承传了下来。并不是任何人都可以对《韦丹塔经》作出自己愚蠢的注释，从而误导读者。任何想要理解《韦丹塔经》的人，都必须认真阅读《圣典博伽瓦谭》。在纳茹阿达牟尼（Nārada Muni）的指导下，维亚萨戴瓦为了解释《韦丹塔经》而编纂了《圣典博伽瓦谭》。在写作《圣典博伽瓦谭》时，维亚萨戴瓦收集了《奥义书》的全部精华，其宗旨在《韦丹塔经》中也得到了说明。因此，《圣典博伽瓦谭》是全部韦达知识的精华。《奥义书》中所陈述、《韦丹塔经》中所重申的内容，在《圣典博伽瓦谭》中得到了非常精彩的解释。

《伊舍奥义书》（Īśopaniṣad）中有一段话，与《圣典博伽瓦谭》（8.1.10）中的一节诗相似，说我们在宇宙显象中所见的一切，都只是至尊主的能量，与祂并无分别。因此，祂是所有生物的控制者、朋友和维系者。我们应当靠神的仁慈生活，只拿分配给我们的东西。这样，不侵占他人的财产，人就能享受生活。

换句话说，《奥义书》、《韦丹塔经》和《圣典博伽瓦谭》的宗旨是同一个。如果认真研读《圣典博伽瓦谭》，就会发现所有《奥义书》和《韦丹塔经》都在其中得到了精彩的解释。《圣典博伽瓦谭》教导我们如何重新建立与至尊主的永恒关系，如何在这种关系中行事，最后，如何从中获得最高的利益。

以 aham eva 开头的四节诗是整部《博伽瓦谭》的要旨。它们是：「我是所有生物关系的至高中心，我的知识是至高的知识。生物能够借以得到我的那种过程，称为阿比戴亚（abhidheya）。借此，人能够达到生命的最高完美，即对神的爱。当一个人得到对神的爱时，他的生命就变得完美。」这四节诗的解释载于《圣典博伽瓦谭》，主采坦尼亚对这些诗节的原则作了简短的描述。祂说，没有人能够理解至尊主的本体地位——祂的处所、祂的超然品质、祂的超然活动以及祂的六种富有。这些无法通过心智揣测或学院教育来理解，只能凭主的仁慈来理解。正如《博伽梵歌》中所述，有幸得到主恩惠的人，凭主的仁慈便能理解所有这些解释。

主在物质创造之前就存在；因此，物质成分、自然和生物都从祂而出，在毁灭之后又栖息于祂之中。当创造显现时，它由祂维系；的确，我们所见的任何显象，都只是祂外在能量的转化。当至尊主收回祂的外在能量时，一切都进入祂之中。在这四节诗的第一节中，aham 一词出现了三次，是为了强调至尊人格神具足一切富有。aham 说了三次，正是为了斥责那些无法理解或相信至尊主超然本性与形体的人。

主拥有祂的内在能量、外在能量、边缘能量和相对能量，以及宇宙世界的显象和生物。外在能量由物质自然的三形态（guṇa）显现出来。能够理解灵性世界中生物本性的人，才真正能够理解 vedyam，即完美的知识。仅仅看着物质能量和受制约的灵魂，是无法理解至尊主的，但当一个人拥有完美的知识时，他就摆脱了外在能量的影响。月亮反射太阳的光，没有太阳，月亮什么也照亮不了。同样，这个物质宇宙显象只是灵性世界的反映。当一个人真正摆脱外在能量的魔力时，他就能理解至尊主的本体本性。对主的奉爱服务是得到主的唯一途径，而这种奉爱服务，任何人在任何国家、任何情况下都可以接受。奉爱服务超越宗教的四项原则，也超越从解脱中获得的理解。甚至奉爱服务的初步阶段，也超然于从解脱中获得的最高理解，以及从普通宗教中获得的理解。

因此，人应当接近一位真正的灵性导师——不论种姓、信仰、肤色、国家等——并从他那里听闻一切关于奉爱服务的事。生命的真正目的，是唤醒我们沉睡的对神的爱。的确，那是我们最终的需要。如何得到那种对神的爱，在《圣典博伽瓦谭》中有解释。有理论知识，也有具体的、觉悟的知识，当一个人领悟了从灵性导师那里所受的教导时，便获得完美的觉悟知识。
