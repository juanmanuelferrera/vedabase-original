### CC Madhya 14.227

> শ্রিয়ঃ কান্তাঃ কান্তঃ পরমপুরুষঃ কল্পতরবো\
> দ্রুমা ভূমিশ্চিন্তামণিগণময়ী তোয়মমৃতম্ ।\
> কথা গানং নাট্যং গগনমপি বংশী প্রিয়সখী\
> চিদানন্দং জ্যোতিঃ পরমপি তদাস্বাদ্যমপি চ ॥২২৭॥

> śriyaḥ kāntāḥ kāntaḥ parama-puruṣaḥ kalpa-taravo\
> drumā bhūmiś cintāmaṇi-gaṇa-mayī toyam amṛtam\
> kathā gānaṁ nāṭyaṁ gamanam api vaṁśī priya-sakhī\
> cid-ānandaṁ jyotiḥ param api tad āsvādyam api ca

*śriyaḥ*——幸运女神；*kāntāḥ*——少女们；*kāntaḥ*——享受者；*parama-puruṣaḥ*——至尊人格神；*kalpa-taravaḥ*——如愿树；*drumāḥ*——所有的树；*bhūmiḥ*——大地；*cintāmaṇi-gaṇa-mayī*——由超然的点金石宝石构成；*toyam*——水；*amṛtam*——甘露；*kathā*——言谈；*gānam*——歌唱；*nāṭyam*——舞蹈；*gamanam*——行走；*api*——也；*vaṁśī*——笛子；*priya-sakhī*——始终的伴侣；*cit-ānandam*——超然的喜乐；*jyotiḥ*——光辉；*param*——至上的；*api*——也；*tat*——那；*āsvādyam*——处处被感受到；*api ca*——也。

**译文**

「『温达文的少女们，即戈丕，是超级的幸运女神。温达文的享受者是至尊人格神奎师那。那里的树全是如愿树，大地由超然的点金石构成。水都是甘露，言谈就是歌唱，行走就是舞蹈，奎师那始终的伴侣是祂的笛子。处处都能体验到超然喜乐的光辉。因此温达文圣地是唯一值得品尝的居所。』」

要旨

这段引文出自《布茹阿玛-桑希塔》（Brahma-saṁhitā 5.56）。
