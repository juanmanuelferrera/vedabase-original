### CC Antya 1.108

> ভৃত্যস্য পশ্যতি গুরূনপি নাপরাধান্\
> সেবাং মনাগপি কৃতাং বহুধাভ্যুপৈতি ।\
> আবিষ্করোতি পিশুনেষ্বপি নাভ্যসূয়াং\
> শীলেন নির্মলমতিঃ পুরুষোত্তমোঽয়ম্ ॥১০৮॥

> bhṛtyasya paśyati gurūn api nāparādhān\
> sevāṁ manāg api kṛtāṁ bahudhābhyupaiti\
> āviṣkaroti piśuneṣv api nābhyasūyāṁ\
> śīlena nirmala-matiḥ puruṣottamo 'yam

*bhṛtyasya*——仆人的；*paśyati*——祂看到；*gurūn*——很严重的；*api*——即使；*na*——不；*aparādhān*——冒犯；*sevām*——服务；*manāk api*——哪怕很微小；*kṛtām*——所做的；*bahu-dhā*——视为极大的；*abhyupaiti*——接受；*āviṣkaroti*——显露；*piśuneṣu*——对敌人；*api*——也；*na*——不；*abhyasūyām*——嫉妒；*śīlena*——以温和的举止；*nirmala-matiḥ*——天性心地纯洁；*puruṣottamaḥ*——至尊人格神，众人格中最优秀者；*ayam*——这位。

**「至尊人格神被称为普茹舒塔玛，是一切人物中最伟大者，祂的心纯洁无染。祂是如此温和，即使祂的仆人牵涉了严重的冒犯，祂也不会认真看待。的确，如果祂的仆人做了一点微小的服务，主也会视之为极大的服务。即使嫉妒的人诽谤主，主也从不对他显露愤怒。祂的伟大品质就是这样。」**

这首诗出自室利拉·茹帕·哥斯瓦米的《奉爱之甘露》（2.1.138）。
