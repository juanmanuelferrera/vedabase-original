### CC Antya 19.107

> ইহার সত্যত্বে প্রমাণ শ্রীভাগবতে ।\
> শ্রীরাধার প্রেম-প্রলাপ ‘ভ্রমর-গীতা’তে ॥১০৭॥

> ihāra satyatve pramāṇa śrī-bhāgavate\
> śrī-rādhāra prema-pralāpa 'bhramara-gītā'te

*ihāra*——这些话的；*satyatve*——真实性；*pramāṇa*——证据；*śrī-bhāgavate*——在《圣典博伽瓦谭》中；*śrī-rādhāra*——室利玛蒂·茹阿达茹阿妮的；*prema-pralāpa*——因狂喜之爱而疯狂地说话；*bhramara-gītāte*——在名为布拉马拉之歌的部分。

**这些话的真实性，在《圣典博伽瓦谭》中有证据。在第十篇名为「布拉马拉之歌」（Bhramara-gītā，即「蜜蜂之歌」）的部分里，室利玛蒂·茹阿达茹阿妮（Rādhārāṇī）出于对奎师那的狂喜之爱，像疯了一样说话。**

当乌达瓦（Uddhava）带着给戈丕（牧牛姑娘）们的信息从马图拉（Mathurā）来到时，戈丕们开始谈论奎师那并哭泣。这时，一位重要的戈丕看见一只蜜蜂，便像疯了一样对它说话，认为这只蜜蜂是乌达瓦的使者，或是乌达瓦和奎师那都非常亲近的人。这些诗节如下 (SB. 10.47.12-21)：

madhupa kitava-bandho mā spṛśāṅghriṁ sapatnyāḥ

kuca-vilulita-mālā-kuṅkuma-śmaśrubhir naḥ

vahatu madhu-patis tan-māninīnāṁ prasādaṁ

yadu-sadasi viḍambyaṁ yasya dūtas tvam īdṛk

「亲爱的蜜蜂啊，你是乌达瓦和奎师那非常狡猾的朋友。你很擅长去碰别人的脚，但我不会被这个误导。你似乎坐在过奎师那某位朋友的胸脯上，因为我看见你的胡须上沾着昆库马（kuṅkuma）粉。奎师那现在正忙着奉承祂在马图拉的所有年轻女友。因此，既然现在可以称祂为马图拉居民的朋友，祂就不需要温达文居民的帮助了。祂没有理由让我们戈丕满意。既然你是这样一个人的使者，你在这里出现有什么用？奎师那一定会为你出现在这个集会中而感到羞愧。」

奎师那是怎样冒犯了戈丕们，以致她们想把祂从心里赶走？答案如下：

sakṛd adhara-sudhāṁ svāṁ mohinīṁ pāyayitvā

sumanasa iva sadyas tatyaje 'smān bhavādṛk

paricarati kathaṁ tat-pāda-padmaṁ tu padmā

hy api bata hṛta-cetā uttama-śloka-jalpaiḥ

「奎师那不再给我们祂双唇那迷人的甘露；相反，祂现在把那甘露给了马图拉的女子。奎师那直接吸引我们的心意，然而祂像你一样是只蜜蜂，因为祂舍弃了美丽花朵的陪伴，去找一朵较差的花。这就是奎师那对待我们的方式。我不明白财富女神为什么继续服侍祂的莲花足，而不把它们弃置一旁。显然她相信奎师那虚假的言语。然而，我们戈丕不像拉克什米（Lakṣmī）那样不明智。」

听到蜜蜂甜美的歌声，并认出蜜蜂是为了让她满意而歌唱奎师那之后，那位戈丕回答说：

kim iha bahu ṣaḍaṅghre gāyasi tvaṁ yadūnām

adhipatim agṛhāṇām agrato naḥ purāṇam

vijaya-sakha-sakhīnāṁ gīyatāṁ tat-prasaṅgaḥ

kṣapita-kucarujas te kalpayantīṣṭam iṣṭāḥ

「亲爱的蜜蜂啊，奎师那主在这里没有住所，但我们知道祂是雅杜帕提（Yadupati）［雅杜王朝之王］。我们非常了解祂，因此不想再听到更多关于祂的歌。你最好去唱给那些如今对奎师那非常亲近的人听。马图拉的那些女子现在有机会被祂拥抱了。她们现在是祂的爱人，因此祂已经平息了她们胸中的灼热。如果你去那里，把你的歌唱给那些幸运的女子听，她们会非常高兴，并且会厚待你。」

divi bhuvi ca rasāyāṁ kāḥ striyas tad durāpāḥ

kapaṭa-rucira-hāsa-bhrūvi-jṛmbhasya yāḥ syuḥ

caraṇa-raja upāste yasya bhūtir vayaṁ kā

api ca kṛpaṇa-pakṣe hy uttamaśloka-śabdaḥ

「哦，采蜜者啊，奎师那一定非常难过，因为见不到我们戈丕。祂必定为对我们的逍遥时光的回忆所折磨。因此祂派你作使者来让我们满意。不要对我们说话！在三界——天界、中界和下界这些必有一死的星球上——所有的女子，对奎师那来说都极易得到，因为祂弯弯的眉毛如此迷人。而且，祂总是受到财富女神非常忠诚的服侍。与她相比，我们微不足道。的确，我们什么也不是。然而，尽管祂非常狡猾，奎师那也非常仁慈。你可以告诉祂，祂因善待不幸之人而受到赞美，因此被称为乌塔玛施洛卡（Uttamaśloka），即被精选的词句和诗节所赞美的人。」

visṛja śirasi pādaṁ vedmy ahaṁ cāṭukārair

anunaya-viduṣas te 'bhyetya dautyair mukundāt

svakṛta iha visṛṣṭāpatya-paty-anya-lokā

vyasṛjad akṛta-cetāḥ kiṁ nu sandheyam asmin

「你在我的脚边嗡嗡作响，只是为了让我原谅你过去的冒犯。请从我脚边走开！我知道穆昆达（Mukunda）教你说这样甜蜜的奉承话，并充当祂的使者。这些的确是聪明的把戏，亲爱的蜜蜂，但我看得出来。这是奎师那的冒犯。不要把我说的话告诉奎师那，尽管我知道你非常嫉妒。我们戈丕舍弃了丈夫、儿子，以及所有许诺更好来生的宗教原则，如今除了服侍奎师那，我们再没有别的事可做。然而奎师那克制了自己的心意，轻易就把我们忘了。因此，不要再提祂了。让我们忘掉彼此的关系吧。」

mṛgayur iva kapīndraṁ vivyadhe lubdha-dharmā

striyam akṛta-virūpāṁ strī-jitaḥ kāmayānām

balim api balim attvāveṣṭayad dhvāṅkṣavad yas

tad alam asita-sakhyair dustyajas tat-kathārthaḥ

「亲爱的蜜蜂啊，当我们回想奎师那过去的诞生时，我们非常害怕祂。在祂化身为茹阿玛昌德拉主（Rāmacandra）时，祂的行为就像一个猎人，不公正地杀死了祂的朋友瓦利（Vāli）。好色的首尔帕那卡（Śūrpaṇakhā）来满足茹阿玛昌德拉的欲望，但祂如此依恋悉达黛薇（Sītādevī），竟割掉了首尔帕那卡的鼻子。在祂化身为瓦玛纳戴瓦（Vāmanadeva）时，祂掠夺了巴利·马哈茹阿佳（Bali Mahārāja），拿走他所有的财物，借口接受他的崇拜而欺骗了他。瓦玛纳戴瓦抓住巴利·马哈茹阿佳，正如人们抓住一只乌鸦。亲爱的蜜蜂啊，与这样的人交朋友不是很好。我知道一旦开始谈论奎师那，就很难停止，我承认我没有足够的力量放弃谈论祂。」

yad-anucarita-līlā-karṇa-pīyuṣa-vipruṭ

sakṛd adana-vidhūta-dvandva-dharmā vinaṣṭāḥ

sapadi gṛha-kuṭumbaṁ dīnam utsṛjya dīnā

bahava iha vihaṅgā bhikṣu-caryāṁ caranti

「关于奎师那的话题如此有力，以至于能摧毁四种宗教原则——宗教、经济发展、感官享乐和解脱。任何人只要通过听闻啜饮哪怕一小滴奎师那卡塔（kṛṣṇa-kathā），就能摆脱一切物质的执著与嫉妒。这样的人如同一只没有生计的鸟，成为托钵者，靠乞讨为生。日常的家务对他来说变得痛苦，他毫不留恋，突然舍弃一切。这样的弃绝虽然十分适宜，但因为我是女人，我无法采取。」

vayam ṛtam iva jihma-vyāhṛtaṁ śraddadhānāḥ

kulikarutam ivājñāḥ kṛṣṇa-vadhvo hiraṇyaḥ

dadṛśur asakṛd etat tan-nakha-sparśatīvra-

smararuja upamantrin bhaṇyatām anya-vārtā

「哦，我亲爱的使者，我就像一只愚蠢的鸟，听到猎人甜美的歌声，出于单纯而相信了它，结果心被刺穿，遭受各种痛苦。因为我们相信了奎师那的话，我们承受了巨大的痛苦。的确，奎师那指甲的触碰伤了我们的脸。祂给我们造成了这么多痛苦！因此，你应当放下关于祂的话题，谈点别的。」

听完室利玛蒂·茹阿迪卡（Rādhikā）的这些话，蜜蜂飞走，随后又飞了回来。经过一番思考，那位戈丕说：

priya-sakha punar āgāḥ preyasā preṣitaḥ kiṁ

varaya kim anurundhe mānanīyo 'si me 'ṅga

nayasi katham ihāsmān dustyaja-dvandva-pārśvaṁ

satatam urasi saumya śrīr vadhūḥ sākamāste

「你是奎师那非常亲爱的朋友，奉祂的命令又来到这里。因此你值得我崇敬。哦，最好的使者，现在告诉我，你有什么请求？你想要什么？奎师那无法舍弃夫妻之爱，因此我明白你来是为了带我们去祂那里。可是你要怎么做呢？我们知道许多财富女神如今住在奎师那的胸膛上，她们比我们服侍得更好，而且不间断。」

她称赞蜜蜂的稳重，然后满怀欢欣地说起来。

api bata madhu-puryām ārya-putro 'dhunā 'ste

smarati sa pitṛ-gehān saumya bandhūṁś ca gopān

kvacid api sa kathā naḥ kiṅkarīṇāṁ gṛṇīte

bhujam aguru-sugandhaṁ mūrdhny adhāsyat kadā nu

「奎师那现在像一位绅士那样住在马图拉的古鲁库拉（Gurukula），忘记了温达文所有的戈丕。可是祂难道不记得父亲南达·马哈茹阿佳（Nanda Mahārāja）那甜美的家吗？我们天生都是祂的侍女。祂难道不记得我们吗？祂是否曾说起我们，还是已经把我们完全忘了？祂还会原谅我们，再一次用那散发着阿古茹（aguru，沉香）香气的手触摸我们吗？」
