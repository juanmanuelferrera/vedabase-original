### CC Antya 6.327

> মহাসম্পদ্দাবাদপি পতিতমুদ্ধৃত্য কৃপয়া\
> স্বরূপে যঃ স্বীয়ে কুজনমপি মাং ন্যস্য মুদিতঃ ।\
> উরোগুঞ্জাহারং প্রিয়মপি চ গোবর্ধনশিলাং\
> দদৌ মে গৌরাঙ্গো হৃদয় উদয়ন্মাং মদয়তি ॥৩২৭॥

> mahā-sampad-dāvād api patitam uddhṛtya kṛpayā\
> svarūpe yaḥ svīye kujanam api māṁ nyasya muditaḥ\
> uro-guñjā-hāraṁ priyam api ca govardhana-śilāṁ\
> dadau me gaurāṅgo hṛdaya udayan māṁ madayati

*mahā-sampat*——巨大的物质富贵；*dāvāt*——从森林大火；*api*——尽管；*patitam*——堕落的；*uddhṛtya*——解救；*kṛpayā*——以仁慈；*svarūpe*——交给斯瓦茹帕·达莫达拉·哥斯瓦米；*yaḥ*——那位（室利·采坦尼亚·马哈帕布）；*svīye*——祂的亲密伴侣；*ku-janam*——卑贱的人；*api*——尽管；*mām*——我；*nyasya*——交付；*muditaḥ*——欣悦；*uraḥ*——胸膛的；*guñjā-hāram*——海螺花环；*priyam*——珍贵的；*api*——尽管；*ca*——和；*govardhana-śilām*——一块戈瓦尔丹山（Govardhana）的石头；*dadau*——给予；*me*——给我；*gaurāṅgaḥ*——高茹安伽主；*hṛdaye*——在我心中；*udayan*——显现；*mām*——我；*madayati*——使我疯狂

**「虽然我是堕落的灵魂、人中最卑贱者，室利·采坦尼亚·马哈帕布仍以祂的仁慈，把我从巨大物质富贵的熊熊森林大火中解救出来。祂欣然把我交给祂的亲密伴侣斯瓦茹帕·达莫达拉。主还把祂戴在胸前的小海螺花环和一块戈瓦尔丹山的石头赐给了我，尽管它们对祂非常珍贵。那位室利·采坦尼亚·马哈帕布在我心中升起，使我为祂而疯狂。」**

这节诗出自茹阿古纳特·达萨·哥斯瓦米所著的《高茹安伽赞颂如意树》（11）。
