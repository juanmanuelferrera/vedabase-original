### CC Madhya 14.227

> শ্রিয়ঃ কান্তাঃ কান্তঃ পরমপুরুষঃ কল্পতরবো\
> দ্রুমা ভূমিশ্চিন্তামণিগণময়ী তোয়মমৃতম্ ।\
> কথা গানং নাট্যং গগনমপি বংশী প্রিয়সখী\
> চিদানন্দং জ্যোতিঃ পরমপি তদাস্বাদ্যমপি চ ॥২২৭॥

> śriyaḥ kāntāḥ kāntaḥ parama-puruṣaḥ kalpa-taravo\
> drumā bhūmiś cintāmaṇi-gaṇa-mayī toyam amṛtam\
> kathā gānaṁ nāṭyaṁ gamanam api vaṁśī priya-sakhī\
> cid-ānandaṁ jyotiḥ param api tad āsvādyam api ca

*শ্রিয়ঃ*—লক্ষ্মীদেবী; *কান্তাঃ*—রমণীগণ; *কান্তঃ*—ভোক্তা; *পরম-পুরুষঃ*—পরম পুরুষোত্তম ভগবান; *কল্প-তরবঃ*—কল্পবৃক্ষ; *দ্রুমাঃ*—সমস্ত বৃক্ষ; *ভূমিঃ*—ভূমি; *চিন্তামণি-গণ-ময়ী*—অপ্রাকৃত স্পর্শমণি রত্নে নির্মিত; *তোয়ম্*—জল; *অমৃতম্*—অমৃত; *কথা*—কথা বলা; *গানম্*—সংগীত; *নাট্যম্*—নৃত্য; *গমনম্*—চলন; *অপি*—ও; *বংশী*—বাঁশি; *প্রিয়-সখী*—নিত্য সঙ্গিনী; *চিৎ-আনন্দম্*—অপ্রাকৃত আনন্দ; *জ্যোতিঃ*—জ্যোতি; *পরম্*—পরম; *অপি*—ও; *তৎ*—সেই; *আস্বাদ্যম্*—সর্বত্র অনুভূত; *অপি চ*—আরও।

**" 'বৃন্দাবনের রমণীগণ, অর্থাৎ গোপীরা, পরম লক্ষ্মীদেবী। বৃন্দাবনের ভোক্তা পরম পুরুষোত্তম ভগবান শ্রীকৃষ্ণ। সেখানকার সমস্ত বৃক্ষ কল্পবৃক্ষ, আর ভূমি অপ্রাকৃত স্পর্শমণিতে নির্মিত। জল সবই অমৃত, কথা বলা মানেই গান, চলা মানেই নৃত্য, আর শ্রীকৃষ্ণের নিত্য সঙ্গিনী তাঁর বাঁশি। অপ্রাকৃত আনন্দের জ্যোতি সর্বত্র অনুভূত হয়। তাই বৃন্দাবন-ধামই একমাত্র আস্বাদ্য ধাম।'**

এটি ব্রহ্মসংহিতা (5.56) থেকে উদ্ধৃত।
