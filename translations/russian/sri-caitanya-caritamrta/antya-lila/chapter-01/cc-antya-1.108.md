### CC Antya 1.108

> bhṛtyasya paśyati gurūn api nāparādhān
> sevāṁ manāg api kṛtāṁ bahudhābhyupaiti
> āviṣkaroti piśuneṣv api nābhyasūyāṁ
> śīlena nirmala-matiḥ puruṣottamo 'yam

*бхр̣тйасйа*—слуги; *паш́йати*—Он видит; *гурӯн*—очень тяжкие; *апи*—хотя; *на*—не; *апара̄дха̄н*—оскорбления; *сева̄м*—служение; *мана̄к апи*—пусть даже самое малое; *кр̣та̄м*—совершённое; *баху-дха̄*—как великое; *абхйупаити*—принимает; *а̄вишкароти*—проявляет; *пиш́унешу*—на врагов; *апи*—также; *на*—не; *абхйасӯйа̄м*—злобу; *ш́ӣлена*—кротким нравом; *нирмала-матих̣*—от природы чистый умом; *пурушоттамах̣*—Верховная Личность Бога, лучшая из всех личностей; *айам*—эта.

**«Верховная Личность Бога, известная как Пурушоттама, величайший из всех живых существ, обладает чистым умом. Он столь кроток, что, даже если Его слуга повинен в тяжком оскорблении, Он не принимает этого всерьёз. Поистине, если Его слуга совершает хотя бы малое служение, Господь принимает его как великое. Даже если завистник поносит Господа, Господь никогда не выказывает ему гнева. Таковы Его великие качества».**

Этот стих взят из *«Бхакти-расамрита-синдху»* (2.1.138) Шрилы Рупы Госвами.
