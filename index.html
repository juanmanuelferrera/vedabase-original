Vedabase Original

The first editions of Śrīla Prabhupāda’s books, the scans they were checked against, and the record of every correction — archived permanently.

Every file here is addressable by path: append its path to this page’s address and the gateway serves you the file. No account, no application, nothing to install. There are no directory listings — a path must name a file, not a folder. The full list of paths is in the manifest below.

Read these first

_index/ The directory — every file in the archive, one link each, grouped by book and language.
corpus/PROVENANCE.md Where all of this came from, what is deliberately absent, and how to check it.
MANIFEST.sha256 The SHA-256 of every published file and a root hash over the whole set — and, because it lists them, the index of every path in this archive.

What is here

corpus/ The text — 86,418 files, in English, Spanish, Portuguese and Hindi.
corpus/isopanisad/iso-1.md
scans/ 71 PDFs of the printed books, including the complete Śrīmad-Bhāgavatam.
scans/adi1.pdf
ocr-packed/ Every page as read by two independent OCR engines, one .tar per book.
ocr-packed/OCR-CONTENTS.sha256
corrections/ The ledger of corrections applied to the text.
audit/ Every discrepancy found: open, arbitrated, applied.
reports/ Each difference shown beside the image of the scanned page.
tools/ The code that did the collation and applied the fixes.
reference-standards/ The reference texts used as a standard.

Checking a file

Fetch it, hash it, and look the hash up in the manifest. If the two agree, what you hold is what was archived — you need not trust whoever served it to you:

curl -sL <this-address>/corpus/isopanisad/iso-1.md | shasum -a 256
grep 'corpus/isopanisad/iso-1.md$' MANIFEST.sha256

Two things worth knowing

A gateway answering 404 does not mean a file is gone. Gateways index the network separately and some lag behind. Ask another — ar-io.dev, ardrive.net and permagate.io all serve the same data — and try again. Only the hash settles anything.

_early-tests/ is not part of the archive. It holds the trial uploads made while working out how to publish this. Nothing on Arweave can be deleted, so they were moved aside and named for what they are. Do not read them as archive content. The same goes for two names that may still resolve at the top level: PROCEDENCIA.md, a Spanish draft that PROVENANCE.md replaced, and prueba-c.md, a test file.
